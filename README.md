## Overview
A beginner-friendly collection of six Jupyter notebooks covering embeddings, cosine similarity, Hugging Face sentence embeddings, ChromaDB vector databases, RAG document chunking, and a practical semantic similarity task.

## Learning objectives
- Understand vector representations and cosine similarity.
- Generate sentence embeddings with Sentence Transformers.
- Understand vector database concepts and ChromaDB.
- Learn document loading and chunking for RAG.
- Compare word and sentence embeddings.
- Apply semantic similarity to a practical task.

## Notebooks
1. Calculating Cosine Similarity Mathematically
2. HuggingFace Embedding Scratch to Intermediate
3. Intro to Vector Databases ChromaDB
4. RAG Step 1: Document Loading and Chunking Strategies
5. Word Embeddings
6. Semantic Similarity Task

## Technologies
Python, NumPy, pandas, scikit-learn, Sentence Transformers, ChromaDB, Jupyter.

## Practical task
Notebook 6 generates sentence embeddings, builds a cosine similarity matrix, finds the closest pair, and searches for the sentence most similar to a new Python-related query.

## Conclusion
The notebooks provide a progressive introduction to semantic representations and retrieval concepts, ending with a small practical semantic similarity task.
